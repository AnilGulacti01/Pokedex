## Overview

This project is a personal Pokémon Pokedex application created to explore Pokémon information using the official PokéAPI. It allows users to search, browse, and discover Pokémon details such as stats, abilities, types, evolution, and more.

The app is built with TypeScript for a cleaner, safer, and more scalable frontend experience.

## Features

- Search Pokémon by name or ID
- Filter by type
- View Pokémon details
- Display stats and abilities
- Browse Pokémon generation data
- Responsive and clean UI
- Fast data fetching from PokéAPI
- Built with modern TypeScript practices

## Tech Stack

- TypeScript
- React / Vite (or your framework if applicable)
- PokéAPI
- CSS / Tailwind / SCSS (depending on your implementation)
- REST API integration
